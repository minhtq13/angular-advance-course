Phần 3 · Vận dụng: xuất danh sách phiếu ra CSV (10 phút)

Yêu cầu mới: Manager muốn nút Xuất CSV trên danh sách phiếu, xuất đúng các phiếu theo bộ lọc đang chọn. Backend sẽ làm GET /api/tickets/export?status=&priority=&category= (trả text/csv, tối đa 10.000 dòng, chỉ SUPERVISOR).

  1. Viết prompt cho AI làm phần frontend: use case, ít nhất 5 acceptance criteria kiểm được, ràng buộc (file nào, theo AGENTS.md), test bắt buộc.
  2. Đoán trước 4 lỗi AI dễ mắc với yêu cầu này và cách bạn sẽ phát hiện từng lỗi (test nào, xem gì trên Network).
  3. Chỉ ra 3 dòng cho báo cáo năng suất mà bạn sẽ đo, và một tiêu chí để quyết định "lần sau tự làm nhanh hơn".
Đáp án tham khảo (chỉ mở sau khi đã viết)
  1. AC ví dụ: nút chỉ hiện với SUPERVISOR (và API trả 403 cho AGENT: test API trực tiếp); request mang đúng bộ lọc đang có trên URL (status, priority, category, assignee khi "Chỉ phiếu của tôi"); file tên phieu-YYYY-MM-DD.csv; đang tải thì nút quay và không bấm lại được; lỗi 403/500 báo bằng chữ đã dịch vi/en; tải bằng HttpClient (responseType: 'blob') để interceptor gắn Bearer (thẻ <a href> trần không gửi token, buổi 6). Ràng buộc: feature không gọi HTTP trực tiếp, thêm export vào TicketPort + adapter + fake.
  2. Ví dụ: dùng <a href> → 401 (Network); quên một bộ lọc (thường assignee/"của tôi") hoặc sai tên tham số → so query string với Swagger, E2E so số dòng CSV với tổng trên màn hình; chỉ ẩn nút mà quên test 403 ở API; URL.createObjectURL không revokeObjectURL (rò bộ nhớ); chữ cứng "Xuất CSV"; fake export không áp bộ lọc nên test xanh.
  3. Phút viết prompt/AC, phút review diff, phút xác minh (test, Network, mở file CSV); số finding đúng/sai. Tiêu chí ví dụ: nếu thời gian xác minh + sửa vượt thời gian ước lượng tự làm, hoặc AI sai ở hợp đồng API hai lần liên tiếp, thì phần đó tự làm, chỉ giao AI phần test bảng và cập nhật spec.
