Loại lib và luật phụ thuộc

Một trang, in được. Dùng cùng bài tập về nhà buổi 1.

Bốn loại lib

LoạiChứaKhông được
featureMàn hình + route của một nghiệp vụImport feature khác
uiComponent trình bày, dữ liệu qua input()/output()Gọi API, import data-access
data-accessService gọi API, model, state phía clientImport ui, feature
utilHàm thuần, type, hằng sốImport bất kỳ loại nào ngoài util

Ai được import ai

app ──► feature ──► ui ─────────► util
                 └──► data-access ──► util
(ui ↛ data-access · feature ↛ feature · util chỉ ↛ util)
Tag nguồnChỉ được import tag
type:appfeature, ui, data-access, util
type:featureui, data-access, util
type:uiui, util
type:data-accessdata-access, util
type:utilutil
scope:portal / scope:adminchính scope đó, scope:shared
scope:sharedscope:shared

Import phải thỏa mọi luật khớp với tag của project nguồn. Project không có tag thì không được import project nào.

Đặt tên

<scope>-<type>-<tên> → import @care/<scope>-<type>-<tên>. Ví dụ portal-feature-subscribers.

npx nx g @nx/angular:library libs/portal/feature-service-plans \
  --name=portal-feature-service-plans --tags=scope:portal,type:feature

Lệnh

npx nx graphXem đồ thị phụ thuộc
npx nx show project <tên>Xem tag, target của một project
npx nx lint <tên>Kiểm luật phụ thuộc của một project
npx nx run-many -t lintKiểm toàn workspace

Hai thông báo lỗi hay gặp

A project tagged with "type:feature" can only depend on libs tagged with
"type:ui", "type:data-access", "type:util"

→ Import sai tầng. Tách phần dùng chung ra lib ui / data-access / util.

Projects cannot be imported by a relative or absolute path, and must begin with a npm scope

→ Import vòng vào file bên trong lib. Export thứ cần dùng ở src/index.ts rồi import qua @care/….

Luật lấy từ frontend/eslint.config.mjs. Nguồn: Nx — Enforce Module Boundaries, Nx — Monorepo Folder Structure.
